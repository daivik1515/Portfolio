This project focuses on building a deep learning-based system for real-time sign language gesture classification, aimed at enhancing communication for individuals with hearing impairments. By comparing CNN architectures - LeNet, VGG and ResNet, the system evaluates model performance using metrics such as accuracy, precision, recall, F1 score and ROC curve. It incorporates transfer learning and hyperparameter optimization for high accuracy and adaptability across diverse datasets.
